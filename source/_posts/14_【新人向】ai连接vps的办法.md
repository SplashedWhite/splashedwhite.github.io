# <center>【新人向】ai连接vps的办法</center>

我看今天有几个帖子在问 AI 怎么连接 VPS，或者怎么让 AI 操作 VPS。一两个月前，我也是在论坛慢慢找帖子，然后才弄成功，于是把大致过程写出来，给大家参考。

下面以 **Windows 本机通过 SSH 连接 VPS** 为例。

先说明一下：这里说的 AI，需要具备执行命令的能力，并且能访问本机的 SSH 配置、私钥和服务器网络。

# 第一种：在 VPS 上安装 AI CLI

这种办法是在 VPS 上安装并运行 AI 命令行工具，完成相应配置后，让它直接在服务器上执行任务。

这里主要说第二种，也就是从自己电脑通过 SSH 连接。

# 第二种：让本机的 AI 通过 SSH 连接 VPS

常见的登录方式有两种：密码登录和密钥登录。

## 一、密码登录

先在自己电脑的 PowerShell 中测试：

```
ssh -p 22 用户名@服务器IP
```

把端口、用户名和 IP 换成自己的，按照提示输入服务器上对应用户的登录密码。

如果手动能登录，再让 AI 使用同样的命令连接。**如果 AI 的执行工具支持口令输入，也可以由它代为输入您提供的密码。** 具体能不能完成，取决于工具支持情况。
即：告诉ai通过`ssh -p 22 用户名@服务器IP`连接，然后告诉它密码即可。

使用密码登录前提是服务器允许这个用户使用密码登录。比如dmit之类的，上来就是密钥，可以直接移步密钥登录了。并且密钥登录也比较方便，配置完成一次之后，使用起来比较方便。

## 二、密钥登录

如果还没有公钥和私钥的话，可以搜一下，几个命令的事儿。或者生成公钥私钥的网站也有很多（注意安全问题）。

但是为了安全起见，我建议自己电脑上使用 ssh-keygen 生成。具体步骤可以参考微软的 Windows SSH 密钥管理教程https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_keymanagement 

或者菜鸟教程中关于ssh密钥的部分，跟着走就行：https://www.cainiaojc.com/ssh/ssh-key.html 

（如果你是新手，可以不用上来就设置密码（私钥口令），先保证登录上，再设置口令也来得及，第一次私钥设置可以是明文的，后面再改也可以，先把流程跑通。后续可以再重新生成公钥私钥，或者给私钥加上口令。如果给同一把私钥添加或修改口令，不需要因此重新配置服务器上的公钥。）

这里假设服务器已经配置好对应的公钥，手里也有用于登录的私钥文件。

为了以后不用每次输入完整地址，可以给服务器配置一个别名。我以自己的服务器为例。

### 1. 配置服务器别名

在下面这个文件中添加配置：

```
C:\Users\用户名\.ssh\config
```

如果 `.ssh` 文件夹不存在，可以手动建立。

**注意：**`.ssh` **前面带点；**`config` **是文件名，没有** `txt` **之类的后缀。**

我把私钥放在了 `config` 旁边：

 ![image](img_posts/config文件.png)

`config` 文件内容：

```
Host dmit-vps
    HostName VPS的IP
    User root
    Port 22
    IdentityFile C:/Users/zxy83/.ssh/dmit.pem
    IdentitiesOnly yes
```

其中：

- `dmit-vps` 是自己给服务器起的别名。
    
- `HostName`、`User`、`Port` 按实际情况填写。
    
- `IdentityFile` 填自己电脑上私钥文件的实际路径。
    
- `IdentitiesOnly yes` 限制用于认证的密钥身份，避免额外尝试代理中的其他密钥。代理里如果有与指定身份对应的密钥，仍然可以使用。


### 2. 私钥设置了密码怎么办？（如果你是新手，可以不用一上来就设置密码，先保证登录上跑通流程，再设置密码或者换公私钥也来得及）

私钥也可以设置一个解锁口令，通常叫 `passphrase`。

如果私钥设置了口令，连接时可能出现：

```
Enter passphrase for key 'C:\Users\用户名\.ssh\dmit.pem':
```

这时输入的是**私钥的解锁口令**，与服务器用户的登录密码不是一回事。

加密私钥文件保存的是加密后的私钥，不会附带一份明文口令。输入口令后，SSH 在本机解锁私钥，再用它完成认证。[OpenSSH 说明](https://man.openbsd.org/ssh.1#FILES)

如果让 AI 连接，且它使用的工具支持口令输入，也可以让它代为输入您提供的私钥口令。这个过程仍然属于密钥登录。

如果没有设置私钥口令，或者密钥已经由代理托管，就可能不需要再次输入。下面还有一个减少重复输入的可选办法。

### 3. 在 PowerShell 中测试

执行：

```
ssh dmit-vps
```

如果需要私钥口令，就按提示输入。

确认能登录后，再对 AI 说：

> 请通过 `ssh dmit-vps` 连接到我的 VPS，先做只读检查，检查内容包括……。

后面接上自己想让它检查的问题即可。

手动测试成功，说明这个 PowerShell 环境能够连接；AI 还需要能访问同样的配置、私钥，并处理可能出现的口令提示。

### 可选：不想反复输入私钥口令

可以使用 `ssh-agent` 管理密钥：先输入一次口令，把密钥加入代理，之后 SSH 就可以请求代理完成认证。

在 **Windows 的** `**ssh-agent**` **已启动**的情况下，执行：

```
ssh-add "C:\Users\用户名\.ssh\dmit.pem"
```

按提示输入私钥口令后，再执行 `ssh dmit-vps`。只要对应密钥仍在代理中可用，SSH 通常就不再重复询问口令。

原来的私钥文件仍然保持加密。AI 能否使用这个代理，也取决于它的运行环境。
